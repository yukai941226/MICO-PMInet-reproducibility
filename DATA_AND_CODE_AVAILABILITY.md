# Code and data availability

All platform-independent code needed for raw spectral preprocessing, animal-level splitting, PLS baselines, the 16-configuration MICO-PMInet experiment, validation-based beta selection, organ-retention evaluation, statistical analysis, checkpoint inference, AWA-weight extraction, and SHAP aggregation is contained in this repository.

The repository includes compressed raw and processed rat ATR-FTIR tables, archived fold-level metrics, an OSB-WMHA-AWA-MORM beta-0.2 checkpoint, and archived SHAP values for that model. `CHECKSUMS.sha256` records integrity hashes.

The default executable workflow follows the article proof. `ARTICLE_ALIGNMENT.md` documents the mapping from stated methods to code and identifies archived numerical artifacts that were not regenerated by the corrected default protocol.
